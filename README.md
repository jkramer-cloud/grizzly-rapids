GRIZZLY RAPIDS V5.1 — STANDALONE GAME (NOT AN UPDATER)

This ZIP contains the complete playable game in a single index.html.

NEW IN V5.1
- Fish words highlight correctly typed letters in green.
- Wrong letters highlight in red on the selected fish.
- Backspace restores the correct/neutral highlighting.
- Previous bear rescue, wolf-pack animations, river levels, vocabulary,
  sound controls, saved high scores, and typing rules are unchanged.

INSTALL
1. Unzip. Open index.html in Chrome or Edge to check the game.
2. Replace the existing root index.html in your GitHub grizzly-rapids repo
   with the index.html from this ZIP. Do not upload an update builder.
3. Commit, then reload your site with Ctrl+Shift+R.

NOTE: Local browser progress is device/browser-specific.
