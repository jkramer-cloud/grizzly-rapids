Publish the update

  1. Save a backup of your current grizzly-rapids/index.html on GitHub.
  2. Click Build my updated index.html above. Your browser will download a new index.html.
  3. Upload that file to the ROOT of your existing grizzly-rapids GitHub repository, replacing the old index.html. Commit your changes.
  4. Reload the live game with Ctrl+Shift+R. No Learning Hub file changes are needed.

Builder does not request GitHub login, does not upload any files, and modifies the copy in your browser only. It fetches the public source from githubusercontent.com. If you previously changed the game and have a newer local index.html, use the file chooser to preserve it.
